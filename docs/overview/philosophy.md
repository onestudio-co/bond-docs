# Philosophy

## Conventions

Prefer clear conventions over ad‑hoc structure. Organize code by features and register dependencies explicitly.

## Explicit Dependencies

Use Service Providers with GetIt. Keep wiring close to each feature and app entry.

## Typed Data

Use shared factories and typed responses for network and cache to reduce boilerplate and errors.

## Developer Experience

First‑class CLI, flavors, and Firebase setup to remove yak‑shaving.
