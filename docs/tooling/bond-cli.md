# Bond CLI

Scaffold projects and features quickly.

## Install

```bash
dart pub global activate bond_cli
```

## Commands

- Create project

```bash
bond create project
```

- Create feature

```bash
bond create feature
```

- Update IDs / names

```bash
bond update application-id
bond update app-name
```

- Add auth integrations (e.g., Google)

```bash
bond add auth google
```
