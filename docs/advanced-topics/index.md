# Advanced Topics

Deep dives for extending and hardening your app.

## Extending Bond packages

- Add custom cache drivers by extending `CacheDriver`
- Implement notification providers and channels
- Provide analytics providers that map system events

## Custom providers and middleware

- Feature Service Providers for APIs, controllers, and model factories
- Dio interceptors for auth, retries, and logging
- Route guards and app‑level middlewares

## Performance

- Cache‑then‑network patterns for perceived latency
- Pagination merging with `XListResponse.merge`
- Minimize rebuilds in forms with granular fields

## Security

- Secure storage for tokens
- Network timeouts and exponential backoff
- Validate and sanitize API inputs/outputs
